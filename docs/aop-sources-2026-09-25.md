# Sources for the AOP entries added on 25 September 2026

The 48 French AOP products added to the atlas on 25 September 2026, and the pages each entry's facts, prices and seasons were taken from. Each entry was drafted from these sources and its facts were then checked a second time against them. Maine-Anjou was left out because the existing Rouge des Prés entry already covers that appellation.
